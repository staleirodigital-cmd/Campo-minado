💣   Campo Minado

Como jogar

Revele todas as casas sem minas para vencer. Cada número indica quantas minas existem nas oito casas ao redor.

Use o botão direito, segure uma casa no celular ou ative o modo bandeira para marcar uma suspeita. Clique em um número aberto quando todas as minas ao redor estiverem marcadas para revelar suas vizinhas.

Teclado: use Tab para navegar, Enter para revelar, F para marcar e F2 para reiniciar.
